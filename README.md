# Continence Gallery

Galeria estatica para GitHub Pages. A pagina busca automaticamente as imagens publicadas na raiz deste repositorio e monta um grid responsivo com busca, ordenacao e visualizacao em tela cheia.

## Como publicar

1. Abra **Settings** no repositorio.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/root`.
5. Salve.

Depois que o GitHub Pages publicar, a galeria ficara em:

```text
https://kalilbubadra.github.io/continence-gallery/
```

Para adicionar novas fotos, envie os arquivos de imagem para a raiz do repositorio. A galeria carrega os novos arquivos automaticamente.
